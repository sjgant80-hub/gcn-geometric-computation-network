The Geometric Computation Network

A distributed computing fabric whose working state is a number. State folds losslessly to one integer; the integer shards by digit-striping across a mesh; shards land on nodes by the golden angle, which provably never clusters; and reassembly is exact, order-free, and loud about absence — a missing shard is named, never interpolated.

No coordinator, no hash ring to rebalance, nothing to disagree about: the state either reassembles to the number that left, or the fabric says which piece is missing. Drafted with sididy, the estate's resident local mind, from Thomas Frumkin's Konomi geometric stack. The document of record is the README of this repository; this page carries the 33/33 mutation-gated reference law, runnable below.

1 · State as a number

A machine state — a list of integers — becomes one integer in base 65537 behind a sentinel digit, so leading zeros and length survive. A state that is a number inherits arithmetic for free: equality is ===, a signature signs one value. The full research codec (primorial folds, entropic torus harmonics) is the estate's geometric-computer, gated.

2 · Sharding by digit-stripe

shard i of k takes digits i, i+k, i+2k … each shard is itself a sentinel-guarded fold, its index aboard → reassembles in ANY order → "incomplete: 2 of 3 shards — the missing piece is not guessable" → duplicates, alien shards, and i === k are each refused by name

3 · Placement by golden angle

Shard s lands at angle s·(1−1/φ) mod 1 around the node ring — deterministic, so any node computes any placement with zero coordination, and golden-angle sequences never cluster for any n (golden-placer, the estate's provably-novel primitive). Consistent hashing without virtual nodes or rebalancing.

4 · Why this is a computation network

With state-as-number as the invariant, the rest of this disclosure family snaps in: MCTP frames carry shards over sound, radio or light; chorus walls gate which node may submit which shard; proof-carrying-models attests which fold a result came from. A mesh of small devices holds and hands around computations none could hold alone — every hop refusable, every absence named.

What already runs · what must catch up

Gated and live today: the reference law in this page (33/33 mutants killed) · geometric-computer · golden-placer · the-cam · the-kg · the-rotor — each mutation-gated in public CI.

The honest speculation: BigInt folding of megabyte states needs hardware or chunking (shards ARE chunks; the silicon is not ours to build) · parity/erasure stripes are future work — this law names a missing shard, it does not recover one · rotors at network scale are years out. Not claimed: performance numbers against DHTs or erasure systems — the claim is the composition, with no coordinator.
